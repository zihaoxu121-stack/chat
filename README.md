# 聊天话术助手 · Windows 客户端

[下载 1.1.1 安装包](https://github.com/zihaoxu121-stack/chat/releases/tag/v1.1.1) · [Windows 构建与实装检查](https://github.com/zihaoxu121-stack/chat/actions/workflows/windows.yml)

64 位 Windows 10 / 11 桌面客户端，自带运行环境；不需要安装 Node.js、Python 或本地模型。只拟稿，不接聊天账号、不代发消息。

## 使用

1. 下载 `ChatDraft-Setup-1.1.1-x64.exe`，双击安装。覆盖安装保留本地数据。
2. 进入“模型与资料设置”，填写 API Base URL、API Key、支持图片的模型名。Base URL 一般以 `/v1` 结尾，程序拼接 `/chat/completions`；兼容接口支持文字与 `image_url` 数据 URL，通过提示词返回 JSON，无需原生 response_format。
3. 点击“导入任务说明书”，选择你的完整 `.txt` 或 `.md` 文件，或复制全文后点击“从剪贴板导入”。先预览数量，再确认导入；本人资料、规范正文与各人的台账分别保存。实际私人说明书不放进公开源码或安装包。没有文件也可手动填写本人资料及联系人。
4. 工作台粘贴/拖入截图，或粘贴文字。文字按消息逐行写“我：”“对方：”。输入不纠错；截图可点开放大。
5. 识别后核对平台、联系人与消息归属，勾选确认再生成。身份不确定必须手选，不自动猜人。
6. 默认三版，每版两气泡。选择“怎么回 · 只给一版主推”则只出一版；“补齐三版”追加缺少的版本。“还有吗/再来一版”只追加一版。
7. 用快捷按钮或指令调整“换个话题”“幽默一点”，直接使用当前身份与聊天，不重问背景；原稿保留在历史。
8. 每个气泡独立复制；整版用单个换行连接，无空行、版号或项目符号。复制从不标记为已发送。

单次最多8张截图，单张12MB，合计约24MB；文字最多5万字。超大尺寸图会提示裁剪。PNG/JPG按解码像素做本轮重复比对，WebP按原文件内容比对；同一PNG元数据变化不会导致重复拟稿。完全相同的输入加相同人物/规范上下文会打开已有草稿。

## 台账与规则

- 五种状态：活跃、待回复、停泊、休眠、已放弃。停泊仅在确认对方主动来聊时回复；已放弃默认不识别匹配、不拟主动追聊，可在台账中明确恢复。
- 导入按平台和明确昵称/别名合并，不跨平台合并。同平台出现多条歧义时不硬合并。导入前保存备份，原有事实保留，补充完整背景和雷区；有冲突请在台账核对并更正。
- 规范正文不夹带其他人的台账、快照、具体人物更正示例或话术示例。出稿只读取当前联系人的已确认资料与最近实际消息，未确认事实提议、历史草稿不作为已发送消息或已知事实。
- 四信号：主动提问、起新话题、分享生活、开启对话。明确证据与弱信号/未知分别显示，证据来自核对后的对方消息。
- 自动记录本轮话题与进度为“模型归纳”。新增事实必须附原文，用户确认才入档；明确更正可在确认时替换旧事实，历史快照仍保留原貌。事实与规范更新后，重复输入不再复用旧上下文草稿。
- 正常先接住，再顺延，语气按熟悉程度和当下回应决定。不编经历，不主动炫耀收入资产。正常道歉不算讨好，前期不急着暧昧。
- 冷场/投入失衡优先“不追问、不硬聊”，允许具体陈述结尾，覆盖常态开放问题、调皮和多钩子要求；对方明确拒绝、不适优先停止推进。说明书例句不覆盖硬规则，不照抄其中冲突的封闭问题或收尾句。
- 生成后经过本地格式/常见违规校验与模型审稿，最多重试一轮；不合格不存有效草稿。识别通常一次请求，拟稿通常两次；费用由你配置的服务计算。

## 本地数据与隐私

安装目录 `%LOCALAPPDATA%\Programs\ChatDraftAssistant`；数据目录 `%APPDATA%\ChatDraftAssistant`，卸载不删数据。原有1.0.x数据自动兼容，不要求搬移目录。

档案、截图（Base64）、历史、本人资料与导入的规范保存本地 JSON。断网可看台账和历史。Windows Key 使用系统 DPAPI 加密，界面不回读，安全存储不可用时拒绝明文保存。导出备份不含 Key，但含聊天隐私；恢复保留本机 API 配置，导入的本人资料与规范随备份恢复。

识别时向指定模型发送当前聊天及候选的身份线索，不发送其他人的完整事实；拟稿只发送当前人资料、本人资料、本轮输入及本人的最近实际记录。无遥测、自动更新或第三方上传；界面禁止网络请求、外部导航和新窗口。API不跟随重定向，只支持HTTPS，本机回环地址可HTTP。

本地聊天数据本身不加密，依赖Windows账户/磁盘保护。不要公开上传个人数据文件、原说明书或聊天备份。Key不能靠复制加密文件跨电脑迁移。

## 验证与边界

核心测试与真实 Electron 界面流程使用模拟模型、本机HTTP服务，不代表真实模型质量。Windows流水线包括中文快捷方式预检、真实安装、检查目标/图标、从快捷方式打开程序、清理旧乱码链接、卸载重装保留数据；未通过不发布。

GitHub Windows runner不等于用户的Windows 10实机。实际API模型的截图识别、语义判断和语气效果仍需真实样本验收；模型审稿不能保证绝对无幻觉。安装包未签名，系统可能显示未知发布者。

## 维护

Node.js 24 LTS，`npm ci` 后：`npm start` 开发启动；`npm test` 核心/集成测试；`npm run test:ui` Electron 界面自动化；`npm run dist:win` 构建 Windows x64 安装包。构建工具首次可能下载 Electron 与 NSIS，用户运行客户端无需这些工具。

`src/handbook.cjs` 本地导入，`store.cjs` 台账/历史，`service.cjs` 识别拟稿流水线，`rules.cjs` 规范校验，`main.cjs` 安全边界与 IPC，`renderer.js` 界面交互。测试夹具仅在未打包并显式启用E2E时可用，不包含在安装包应用中。
